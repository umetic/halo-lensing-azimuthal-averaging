# Halo-Lensing Azimuthal Averaging

Paper-specific reference implementation and reproduction package for the
controlled halo-lensing calculations and population experiments presented in
Umetsu (2026), "Why Azimuthal Averaging Works in Halo Lensing: Symmetry and
Power Counting for Nonlinear Shear and Magnification."

This repository is under development. The scientific implementation,
reference outputs, environment specification, and reproduction instructions
will be added after validation against the frozen publication calculations.
