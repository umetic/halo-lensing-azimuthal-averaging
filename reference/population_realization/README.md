# Population-realization reference targets

`population_targets.json` contains compact validation anchors derived from the frozen publication catalogs. They are used to verify the stochastic realization layer: grid ordering, seed schedule, concentration/shape draw order, projected halo properties, and independent offset streams.

The reference file is not a replacement for the publication catalogs and is not used to generate science results. It intentionally stores selected values, summary statistics, and stable hashes for deterministic checks.
