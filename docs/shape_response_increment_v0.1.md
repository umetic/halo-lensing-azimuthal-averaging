# Shape-response increment v0.1

This increment implements the centered projected-shape response analysis used
for the paper's Figure 3 numerical table.  The code is organized by the
scientific diagnostic, not by the final plotting product.

Scope:

- select the centered `sigma_d=0` population, `z_s=1`, and the actual key radius
  `R/r200c = 0.2924408238028535`;
- apply the far-background outer mask supplied by the population-field layer;
- bin retained halos by `epsilon_perp**2` using ten quantile-edge bins and
  `searchsorted(..., side="right")` for internal-edge ties;
- compute the strict halo-level leading coefficient `A_epsilon` from the
  projected circular NFW reference of each halo;
- summarize direct residual medians and
  `median(A_epsilon_i * epsilon_perp_i**2)` for each grid/bin;
- preserve the distinction between the strict leading prediction and the
  finite-field second-order diagnostic.

Non-scope:

- no Figure 3 rendering;
- no Table 2 common-domain cut;
- no Section 6 hybrid/conditioning diagnostics;
- no alignment reweighting;
- no population field evaluation.

The implementation consumes population key samples generated by earlier layers
or synthetic test products.  Full publication-size validation against freshly
generated field products remains a later end-to-end gate.
